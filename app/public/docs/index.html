Vesper MCP server

Give any AI agent a construction project's verified site record and memory — drawings with revisions, RFIs, permits, hold points, IS codes, 550 QA/QC templates and your PDFs. Vesper answers with citations, abstains when the evidence is weak, and refuses to log work that contradicts the latest drawing or an open permit.

MCP 2025-06-18Streamable HTTP11 toolsClerk JWT authPer-project scopingOpen source
Quickstart →Run the server and call your first tool in two minutes. Connect a client →Claude Code, Claude Desktop, Cursor, VS Code. Tools reference →Inputs, outputs and safety annotations. Backends →Copy-ready Python, TypeScript, Go and cURL.

Endpoint. POST {BASE_URL}/mcp — JSON-RPC 2.0. The same tools are also plain REST at GET /api/tools and POST /api/tools/{name}. The public demo on this site is static; run the backend locally or on your own host to call tools.

check_site_statement

Runs an English or Hinglish site statement through the deterministic contradiction engine: superseded revisions, tolerance breaches, unmet permit checks and unreleased hold points. Pass sessionId back for follow-ups and corrections. It may create a pending observation when the user confirms, so it is annotated readOnlyHint: false.

Protocol

Protocol version 2025-06-18 over Streamable HTTP with single JSON responses (no SSE stream, no batching).

MethodResult
initializeprotocolVersion, serverInfo, capabilities.tools, instructions
notifications/initialized202 Accepted (any message without id)
ping{}
tools/list{ tools: [...] } with JSON Schema inputSchema and annotations
tools/call{ content: [{type:"text", text}], structuredContent, isError }

Python

# pip install mcp
import asyncio, os
from mcp import ClientSession
from mcp.client.streamable_http import streamablehttp_client

URL = os.getenv("VESPER_MCP_URL", "http://127.0.0.1:8000/mcp")
HEADERS = {"Authorization": f"Bearer {os.environ['VESPER_TOKEN']}"} if os.getenv("VESPER_TOKEN") else {}

async def main():
    async with streamablehttp_client(URL, headers=HEADERS) as (read, write, _):
        async with ClientSession(read, write) as s:
            await s.initialize()
            tools = await s.list_tools()
            print([t.name for t in tools.tools])
            r = await s.call_tool("ask_memory", {"query": "Which permits are blocking work today?", "projectId": "NSK"})
            print(r.structuredContent["answer"])

asyncio.run(main())
# pip install httpx
import itertools, os, httpx

class Vesper:
    def __init__(self, url="http://127.0.0.1:8000/mcp", token=os.getenv("VESPER_TOKEN")):
        self.url, self.ids = url, itertools.count(1)
        self.http = httpx.Client(timeout=180, headers={"Authorization": f"Bearer {token}"} if token else {})

    def rpc(self, method, params=None):
        r = self.http.post(self.url, json={"jsonrpc": "2.0", "id": next(self.ids), "method": method, "params": params or {}})
        body = r.json()
        if "error" in body: raise RuntimeError(body["error"])
        return body["result"]

    def call(self, name, **args):
        res = self.rpc("tools/call", {"name": name, "arguments": args})
        if res["isError"]: raise RuntimeError(res["content"][0]["text"])
        return res["structuredContent"]

v = Vesper()
v.rpc("initialize")
print(v.call("ask_memory", query="Who is the structural consultant?", projectId="NSK")["answer"])
verdict = v.call("check_site_statement", projectId="NSK", text="Sump ki excavation restart karo")
print(verdict["state"], verdict["reply"]["text"])

const URL_ = process.env.VESPER_MCP_URL ?? "http://127.0.0.1:8000/mcp";
let id = 0;

export async function vesper<T = unknown>(name: string, args: Record<string, unknown> = {}): Promise<T> {
  const r = await fetch(URL_, {
    method: "POST",
    headers: { "Content-Type": "application/json", ...(process.env.VESPER_TOKEN ? { Authorization: `Bearer ${process.env.VESPER_TOKEN}` } : {}) },
    body: JSON.stringify({ jsonrpc: "2.0", id: ++id, method: "tools/call", params: { name, arguments: args } }),
  });
  const body = await r.json();
  if (body.error) throw new Error(body.error.message);
  if (body.result.isError) throw new Error(body.result.content[0].text);
  return body.result.structuredContent as T;
}

const a = await vesper<{ answer: string; abstain: boolean }>("ask_memory", { query: "Who is the structural consultant?", projectId: "NSK" });
console.log(a.abstain ? "not in the record" : a.answer);

Go

main.go
package main

import (
	"bytes"
	"encoding/json"
	"fmt"
	"net/http"
	"os"
)

func call(name string, args map[string]any) (map[string]any, error) {
	body, _ := json.Marshal(map[string]any{"jsonrpc": "2.0", "id": 1, "method": "tools/call",
		"params": map[string]any{"name": name, "arguments": args}})
	req, _ := http.NewRequest("POST", "http://127.0.0.1:8000/mcp", bytes.NewReader(body))
	req.Header.Set("Content-Type", "application/json")
	if t := os.Getenv("VESPER_TOKEN"); t != "" {
		req.Header.Set("Authorization", "Bearer "+t)
	}
	resp, err := http.DefaultClient.Do(req)
	if err != nil {
		return nil, err
	}
	defer resp.Body.Close()
	var out struct {
		Result struct {
			StructuredContent map[string]any `json:"structuredContent"`
			IsError           bool           `json:"isError"`
		} `json:"result"`
	}
	return out.Result.StructuredContent, json.NewDecoder(resp.Body).Decode(&out)
}

func main() {
	r, err := call("ask_memory", map[string]any{"query": "What cover does IS 456 require for columns?", "projectId": "P1"})
	fmt.Println(r["answer"], err)
}

Production checklist

  1. Deploy the backend behind HTTPS — Fly.io, Render, Railway or a VPS. The Cloudflare site is static and has no /mcp.
  2. Set CLERK_JWT_ISSUER so every call needs a Clerk JWT; front it with an OAuth 2.1 proxy for MCP-spec authorization if clients need it.
  3. Allow your client origins in CORS for browser-based agents.
  4. Rate-limit /mcp and /api/tools/* — reranking is the main cost (~0.4 s per uncached search).
  5. Smoke test with tools/list and one ask_memory call, then register the public URL in your client or an MCP directory.

FAQ

Does Vesper hallucinate answers?

Answers are built only from retrieved passages. If the reranked evidence is weak, ask_memory returns abstain: true, and sentences quoting numbers absent from the sources are removed.

Can an agent write bad data?

Only check_site_statement can lead to a write, and the deterministic engine blocks logs that contradict the latest drawing revision, tolerances, open permits or hold points.

Which languages are supported?

English, Hindi and Hinglish statements; answers are returned in English with citations.
